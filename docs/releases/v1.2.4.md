# S2 Report Sniffer v1.2.4

## Evidence-first SingleStore diagnostics—now packaged for every major desktop platform

This release completes the 1.2 correctness and explainability work with validated native packages for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64.

## Download

Expand **Assets** below:

| Your computer | Package |
|---|---|
| macOS — Apple Silicon (M1/M2/M3/M4) | `*-arm64.dmg` |
| macOS — Intel | the other `.dmg` |
| Windows 10/11 x64 | `.exe` |
| Linux x64 | `.AppImage` or `.deb` |

Verify your package against the matching `SHA256SUMS-*` manifest:

```bash
shasum -a 256 "/path/to/downloaded/package"
```

> **Unsigned community build:** macOS and Windows may show an unidentified-developer warning. Download only from this official repository and verify the checksum. On macOS, Control-click the app and choose **Open**. On Windows, choose **More info → Run anyway**.

## Highlights

### Query and tracing accuracy
- Processlist time is current-state age, not assumed end-to-end runtime.
- Sleeping/system sessions are excluded from active-query findings.
- Blocker identities and `REASON_FOR_QUEUEING` use documented fields.
- Client hosts are not mislabeled as cluster nodes.
- Query-scoped evidence is separated from node-level log-window correlation.
- Unverified partition routing is labeled unknown.

### Replication without invented lag
- Measured elapsed lag is separate from LSN/volume backlog and catch-up estimates.
- Connectivity, paused links, throttling, async transitions, backlog, and unknown lag are distinct signals.
- Historical transitions alone do not claim a current critical failure.

### Explainable findings
- New explainer catalog and `GET /api/explainers` endpoints.
- Clear separation of documented behavior, Toolbox defaults, observations, and Sniffer heuristics.
- Transparent **Finding Severity Index** terminology replaces ambiguous cluster-health wording.

### System, storage, and security
- CPU/network counters are labeled cumulative since boot; loopback traffic is excluded.
- Replica roles and incomplete topology inputs are handled honestly.
- Table-skew analysis uses exact population CV, correct MiB units, and guarded idle-leaf detection.
- Backend, frontend, Electron, and packaging dependencies are updated past known production advisories.
