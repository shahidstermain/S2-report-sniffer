# S2 Report Sniffer v1.2.15

## Faster Cluster Report upload and dashboard open

Version 1.2.15 shortens anonymized tracelog indexing during upload and stops Overview from re-reading an extracted Cluster Report on every open when that report has no events, CPU, or network diagnostics.

## Download

Expand **Assets** on the [v1.2.15 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.15):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2.Report.Sniffer-1.2.15-arm64.dmg` |
| Intel | `S2.Report.Sniffer-1.2.15-x64.dmg` |

Verify the package against `SHA256SUMS-macos` or `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2.Report.Sniffer-1.2.15-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **Faster anonymized upload:** Tracelog indexing still redacts every line, but it only rewrites the message, hostname, and source. Timestamps, severities, roles, and ports are copied through. On a 40,000-line sample the anonymized timeline build dropped from 14.9s to 2.4s, with the same replacement count.
- **Overview opens once:** A Cluster Report with no events, CPU, or network data was re-parsed on every Overview open. That parse now runs off the request thread, the empty result is saved, and later opens skip it. Rehydrate still parses when you ask it to.
- **Nodes stays responsive:** Recomputing CPU health for the Nodes tab no longer runs on the request thread.
