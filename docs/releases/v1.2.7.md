# S2 Report Sniffer v1.2.7

## Official SingleStore collector alignment, unknown-health preservation, and anonymizer hardening

Version 1.2.7 eliminates false-critical findings on documented SingleStore collector schemas (`SHOW CLUSTER STATUS`, `SHOW PARTITIONS`, `MV_BLOCKED_QUERIES`, and missing `transparentHugepage` host collectors), fixes FQDN anonymization in `ip_addr`, preserves `unknown` health states across the backend and UI, and hardens bundled macOS desktop startup and viewport scaling.


> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **Accurate HA partition redundancy checks (`userDatabaseRedundancy`):** Recognizes official `SHOW CLUSTER STATUS` / `MV_CLUSTER_STATUS` column `STATE` (`DATABASE_NAME`) and treats documented healthy replica state `replicating` alongside `online` and `healthy`.
- **Accurate partition master mapping (`unmappedMasterPartitions`):** Resolves official `SHOW PARTITIONS` columns (`Ordinal`, `Host`, `Role`) so `Role=Slave` rows sharing an `Ordinal` with `Role=Master` are no longer reported as unmapped masters or duplicate partitions.
- **Accurate lock contention chain grouping (`severeLockContention` / `blockedQueries`):** Groups `MV_BLOCKED_QUERIES` chains by documented `BLOCKING_ID` (and uppercase `KILL_STATUS`) so unrelated blocked queries do not collapse into a single synthetic `"unknown"` chain.
- **Missing THP collector handling (`transparentHugepage`):** Treats missing `transparentHugepage` / `thp` collector directories (`status=unknown`) as unavailable rather than reporting THP as enabled.
- **Privacy & anonymizer hardening:** Masks FQDNs appearing only in `cluster_overview.nodes_detail[].ip_addr` (`MV_NODES.Host`) as `NODE_*` aliases while keeping IPv4/IPv6 literals on `IP_*`.
- **Unknown health preservation & dashboard fit:** Preserves `null` / `unknown` health metrics when analysis is incomplete or absent, renders neutral `CircleHelp` icons in Recent Activity and the report table, normalizes Electron window zoom to 100%, and removes the synthetic demo workspace.
- **Bundled desktop startup fix:** Ensures the bundled FastAPI backend starts cleanly and passes health checks in packaged macOS builds.
