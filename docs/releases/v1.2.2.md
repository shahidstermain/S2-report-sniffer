# S2 Report Sniffer v1.2.2

## Grounded diagnostics, safer dependencies, and reliable multi-platform packages

S2 Report Sniffer v1.2.2 is the first complete multi-platform release of the 1.2 analysis-correctness work. It improves how query, replication, system, and storage evidence is interpreted—and explains more clearly what each result does and does not prove.

## Download

Expand **Assets** below and choose:

| Your computer | Package |
|---|---|
| macOS — Apple Silicon (M1/M2/M3/M4) | `*-arm64.dmg` |
| macOS — Intel | the other `.dmg` |
| Windows 10/11 x64 | `.exe` |
| Linux x64 | `.AppImage` or `.deb` |

Every platform includes a `SHA256SUMS-*` manifest:

```bash
shasum -a 256 "/path/to/downloaded/package"
```

> **Unsigned community build:** macOS and Windows may show an unidentified-developer warning. Download only from this official repository and verify the checksum. On macOS, Control-click the app and choose **Open**. On Windows, choose **More info → Run anyway**.

## What is new

### Query analysis that respects SingleStore semantics
- Treats `MV_PROCESSLIST.TIME` as age in the current process state, not guaranteed end-to-end query runtime.
- Excludes sleeping and system sessions from active-query findings.
- Uses documented blocker identities and `REASON_FOR_QUEUEING`.
- Stops treating a client `HOST` as a cluster node.
- Distinguishes query-scoped evidence from node-level log-window correlation.
- Labels unverified partition routing as unknown instead of claiming single-partition execution.

### Replication analysis without invented lag
- Separates directly measured elapsed lag from LSN/volume backlog and catch-up estimates.
- Reports connectivity failures, paused links, throttling, async transitions, backlog, and unknown elapsed lag independently.
- Does not treat historical sync-to-async transitions alone as proof of a current critical failure.

### Explainability and honest scoring
- Adds an explainer catalog for KPI meaning, derivation, evidence basis, and honesty notes.
- Adds `GET /api/explainers` and `GET /api/explainers/{id}`.
- Distinguishes documented behavior, Toolbox defaults, observed evidence, and Sniffer-owned heuristics.
- Documents the score as a **Finding Severity Index**, not measured cluster health or an official SingleStore verdict.

### System, storage, and security
- Labels CPU and network counters as cumulative since boot.
- Excludes loopback traffic from network summaries.
- Recognizes synchronous/asynchronous replica roles and marks incomplete topology counts as lower bounds.
- Retains improved table-skew analysis with exact population CV, correct MiB conversion, and guarded idle-leaf detection.
- Updates backend, frontend, Electron, and packaging dependencies past known production advisories.

## Privacy and upgrades

- Report data stays under `S2RS_DATA_DIR`; no automatic report upload or product telemetry is enabled.
- Existing reports and settings remain compatible.
- Stale persisted query/replication analysis is refreshed by analysis revision.
- Compatible Disk Intelligence payloads hydrate from saved normalized signals.
- Glean incident packets stay local until you explicitly attach them.
