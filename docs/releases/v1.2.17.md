# S2 Report Sniffer v1.2.17

## Signal Lens icon and SingleStore brand colors

Version 1.2.17 replaces the app icon and the purple accent with the Signal Lens mark and the current SingleStore brand palette.

## Download

Expand **Assets** on the [v1.2.17 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.17):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2 Report Sniffer-1.2.17-arm64.dmg` |

Verify the package against `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2 Report Sniffer-1.2.17-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **New app icon.** The desktop icon, the browser tab icon, and the dashboard hero show a database cylinder with a magnifier.
- **Current SingleStore purple.** Buttons, badges, and progress use Purple 700 (`#820DDF`). In dark mode, purple text uses Purple 500 (`#D199FF`) so it stays readable on dark surfaces.
- **Small sizes stay clear.** The favicon uses the two-ring form of the mark.
