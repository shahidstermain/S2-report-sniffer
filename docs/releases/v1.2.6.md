# S2 Report Sniffer v1.2.6

## Guided investigation and macOS-focused distribution

Version 1.2.6 adds a deterministic synthetic workspace for learning the product without customer data and focuses official desktop packages on macOS.

## Download

Expand **Assets** on the [v1.2.6 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.6):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2.Report.Sniffer-1.2.6-arm64.dmg` |
| Intel | `S2.Report.Sniffer-1.2.6.dmg` |

Verify the package against `SHA256SUMS-macos` or the matching architecture manifest:

```bash
shasum -a 256 "/path/to/S2.Report.Sniffer-1.2.6*.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- Launch **Demo: Active Incident** and **Demo: After Remediation** from Guided help.
- Explore production-shaped findings, health scoring, logs, queries, storage, and remediation flows without customer diagnostics.
- Use capability-aware tours, contextual page explanations, and a grounded metric glossary.
- Present a complete disk-pressure story with mount usage, table-attributed bytes, non-table overhead, HA-adjusted blob estimates, storage types, partitions, and post-remediation comparison.
- Keep Guided Help visible in compact app windows with a viewport-bounded, internally scrollable modal.
- Navigate the tour with the keyboard; use **Escape** to close it.
- Continue normally when browser preference storage is blocked.

## Correctness and safety

- Demo findings use the production recommendation and triage schema.
- Finding Severity Index values use the same critical/warning formula as imported reports.
- Synthetic timestamps remain within their report snapshots.
- Concurrent demo launches are idempotent.
- Demo reports are clearly labeled and excluded from real-report KPI totals.
