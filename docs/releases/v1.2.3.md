# S2 Report Sniffer v1.2.3

## Evidence-first diagnostics for macOS, Windows, and Linux

This release delivers the 1.2 analysis-correctness work in a validated cross-platform desktop package. Query, replication, system, and storage findings now describe what the collected evidence actually proves—and explicitly label uncertainty where a Cluster Report cannot support a stronger conclusion.

## Download

Expand **Assets** below:

| Your computer | Package |
|---|---|
| macOS — Apple Silicon (M1/M2/M3/M4) | `*-arm64.dmg` |
| macOS — Intel | the other `.dmg` |
| Windows 10/11 x64 | `.exe` |
| Linux x64 | `.AppImage` or `.deb` |

Every platform includes a `SHA256SUMS-*` manifest:

```bash
shasum -a 256 "/path/to/downloaded/package"
```

> **Unsigned community build:** macOS and Windows may show an unidentified-developer warning. Download only from this official repository and verify the checksum. On macOS, Control-click the app and choose **Open**. On Windows, choose **More info → Run anyway**.

## Highlights

### Query analysis
- Treats `MV_PROCESSLIST.TIME` as age in the current process state—not guaranteed end-to-end runtime.
- Excludes sleeping and system sessions from active-query findings.
- Uses documented blocker identities and `REASON_FOR_QUEUEING`.
- Separates query-scoped evidence from node-level log-window correlation.
- Labels unverified partition routing as unknown.

### Replication analysis
- Separates directly measured lag from LSN/volume backlog and catch-up estimates.
- Reports connectivity, paused links, throttling, async transitions, backlog, and unknown elapsed lag independently.
- Does not turn historical transition evidence alone into a current critical-state claim.

### Explainability
- Adds a KPI and checker explainer catalog with derivation, evidence basis, and honesty notes.
- Adds `GET /api/explainers` and `GET /api/explainers/{id}`.
- Distinguishes documented behavior, Toolbox defaults, observations, and Sniffer heuristics.
- Renames the documented score to **Finding Severity Index** so it is not mistaken for official cluster health.

### Accuracy and security
- Labels CPU/network counters as cumulative since boot and excludes loopback traffic.
- Handles synchronous/asynchronous replica roles and incomplete topology inputs.
- Retains exact-CV table-skew analysis with correct MiB units and guarded idle-leaf detection.
- Updates backend, frontend, Electron, and packaging dependencies past known production advisories.

## Privacy and upgrades

- Report data stays under `S2RS_DATA_DIR`; no automatic report upload or telemetry is enabled.
- Existing reports/settings remain compatible.
- Stale persisted query/replication analysis refreshes by analysis revision.
- Compatible Disk Intelligence payloads hydrate from saved normalized signals.
- Glean packets remain local until you explicitly attach them.
