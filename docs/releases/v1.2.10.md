# S2 Report Sniffer v1.2.10

## Query Tracer end-to-end transparency and correlation insights

Version 1.2.10 brings end-to-end transparency to Query Tracer, explaining how offline diagnostic snapshots are stitched together, clarifying observed vs inferred stages, and detailing confidence scoring factors.

## Download

Expand **Assets** on the [v1.2.10 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.10):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2.Report.Sniffer-1.2.10-arm64.dmg` |

Verify the package against `SHA256SUMS-macos` or `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2.Report.Sniffer-1.2.10-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **Correlation methodology note:** Informs users how `SHOW PROCESSLIST` (state, elapsed time), `MV_BLOCKED_QUERIES` (blocker connection and node IDs), and node tracelogs are joined across nodes.
- **Observed vs Inferred clarity:** Flow and Timeline views clearly distinguish stages backed by direct snapshot rows (solid lines) from architectural SingleStore execution models (dashed lines).
- **Trace classification & routing guidance:** Interactive `InfoHint` tooltips explain how queries are categorized into Lock wait, Runaway, or Slow, and why partition routing defaults to fan-out when shard-key DDL is omitted.
- **Confidence breakdown & evidence inspector:** Details the positive and negative weights contributing to the confidence score, and allows clicking any stage to inspect underlying snapshot rows and metrics.
