# S2 Report Sniffer v1.2.13

## Real-Time CPU Analytics & High-Performance Node Health

Version 1.2.13 resolves misleading cumulative CPU counters, restores real-time CPU utilization snapshot visualization, drastically improves the loading speed of the Nodes section, and fixes tracelog timeline ordering.

## Highlights

- **Instantaneous CPU Utilization (top snapshots):** Previously, CPU health was derived exclusively from `MV_SYSINFO_CPULIST` cumulative nanoseconds since host boot, causing multi-day uptime nodes to flatten to a static cluster average (~50%). The CPU Health panel now extracts real-time CPU load from host `top` snapshots (`%Cpu(s): id, us, sy, wa, si, st`) mapped to SingleStore `NODE_ID`s.
- **Dual-Mode Interactive CPU Panel:** The CPU Health panel defaults to Current CPU (Snapshot) with an interactive toggle to inspect Lifetime Avg (Since Boot) whenever cumulative metrics exist, side-by-side in both charts and tables.
- **Sub-Millisecond Nodes View:** Discarded megabytes of unnecessary non-node collectors (`information_schema_tables`, `database_status`, `ps`, and raw sysinfo) from the `/reports/{id}/nodes` endpoint, cutting payload sizes by 58x–100x+ (e.g. from 2.76MB down to 47KB). Added an in-memory mtime-validated payload cache in `LocalReportStore` and client-side tab state caching in `NodeHealth.jsx` for instantaneous tab navigation.
- **Node Tracelog Timeline & Chronological Ordering:** Tracelog viewer displays events across all nodes chronologically with per-node filtering and Master Aggregator role fallback.
