# S2 Report Sniffer v1.2.13

## Tracelog Timeline, Topology Accuracy & Dependency Fixes

Version 1.2.13 brings chronological cross-node tracelog timelines, partition topology accuracy improvements, and dependency updates.

## Download

Expand **Assets** on the [v1.2.13 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.13):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2.Report.Sniffer-1.2.13-arm64.dmg` |
| Intel | `S2.Report.Sniffer-1.2.13-x64.dmg` |

Verify the package against `SHA256SUMS-macos` or `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2.Report.Sniffer-1.2.13-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **Node Tracelog Timeline & Chronological Ordering:** Tracelog viewer displays events across all nodes chronologically with per-node filtering and Master Aggregator role fallback.
- **Partition Topology Accuracy:** Validated topology representation and partition distribution across cluster leaves.
- **Dependency Security Updates:** Resolved pip and npm advisory vulnerabilities.
