# S2 Report Sniffer v1.2.16

## Same Cluster Report replaces the earlier analysis

Version 1.2.16 replaces the previous analysis when you upload or import the same Cluster Report file again. The new analysis has to finish successfully. If it fails, the earlier report stays.

Reports already stored by 1.2.15 or earlier have no content fingerprint, so upload that file once more with this version before a later copy can replace it.

## Download

Expand **Assets** on the [v1.2.16 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.16):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2 Report Sniffer-1.2.16-arm64.dmg` |

Verify the package against `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2 Report Sniffer-1.2.16-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **One analysis per file.** A second upload or import of the same archive replaces the earlier report after the new analysis reaches ready. The list keeps the new report.
- **The previous report stays until success.** While the new copy is processing, and if that processing fails, the earlier analysis remains available.
- **You can keep both.** Pass `replace_duplicates=false` on upload or import to store a second copy.
