# S2 Report Sniffer v1.2.1

## Evidence-first analysis, clearer grounding, and multi-platform packages

This release focuses on one principle: every result should say what the source data actually proves.

### Download

Expand **Assets** below and choose the package for your computer:

| Platform | Choose |
|---|---|
| macOS — Apple Silicon (M1/M2/M3/M4) | the `arm64.dmg` file |
| macOS — Intel | the other `.dmg` file |
| Windows 10/11 x64 | the `.exe` installer |
| Linux x64 | `.AppImage` or `.deb` |

Each platform also has a `SHA256SUMS-*` manifest. Verify a download with:

```bash
shasum -a 256 "/path/to/downloaded/package"
```

> **Unsigned community build:** macOS and Windows may show an unidentified-developer warning. Download only from this official repository and verify the checksum. On macOS, Control-click the app and choose **Open**. On Windows, choose **More info → Run anyway**.

## Highlights

### Query analysis that respects source semantics
- `MV_PROCESSLIST.TIME` is treated as age in the current process state—not guaranteed end-to-end query runtime.
- Sleeping and system sessions no longer become active-query findings.
- Query tracing uses documented blocker identities and `REASON_FOR_QUEUEING`.
- Client `HOST` is no longer mislabeled as a cluster node.
- Node-level log-window matches do not masquerade as evidence for a specific query.
- Unverified partition routing is labeled unknown instead of single-partition.

### Replication analysis without invented lag
- Directly measured elapsed lag is separated from LSN/volume backlog and catch-up estimates.
- Connectivity failures, paused links, throttling, async transitions, backlog, and unknown lag are reported independently.
- Historical transition evidence alone does not claim that the current link is critically unhealthy.

### Grounding and explainability
- New explainer catalog defines KPI meaning, derivation, evidence basis, and honesty notes.
- New API endpoints: `GET /api/explainers` and `GET /api/explainers/{id}`.
- Findings distinguish documented behavior, Toolbox defaults, observed evidence, and Sniffer-owned heuristics.
- The UI documentation now calls the score what it is: a **Finding Severity Index**, not official cluster health.

### System and storage accuracy
- CPU and network counters are labeled as cumulative since boot.
- Loopback traffic is excluded from network summaries.
- Cluster layout recognizes synchronous/asynchronous replica roles and marks incomplete inputs as lower bounds.
- Table-skew analysis retains exact population CV, correct MiB conversion, and guarded idle-leaf detection.

### Security and distribution
- Backend and frontend dependencies were updated to clear known production audit findings.
- Electron and electron-builder were upgraded to patched current releases.
- Native packages are built for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64.
- Source, documentation, issues, and downloads now live in this one canonical repository.

## Upgrade notes

- Existing local reports and settings remain under `S2RS_DATA_DIR`.
- Persisted query and replication analysis is refreshed when its analysis revision is stale.
- Compatible older Disk Intelligence payloads continue to hydrate from saved normalized signals.
- No report data is sent automatically. Glean packets remain local until you explicitly attach them.
