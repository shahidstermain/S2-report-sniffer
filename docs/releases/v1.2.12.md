# S2 Report Sniffer v1.2.12

## UI Simplification, Navigation Consolidation & Air-Gap Hardening

Version 1.2.12 focuses on usability, cognitive decluttering, and air-gapped security. It eliminates redundant navigation tabs, consolidates storage and log analysis, streamlines the report intake landing page, and cleans up dead integrations.

## Download

Expand **Assets** on the [v1.2.12 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.12):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2.Report.Sniffer-1.2.12-arm64.dmg` |
| Intel | `S2.Report.Sniffer-1.2.12-x64.dmg` |

Verify the package against `SHA256SUMS-macos` or `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2.Report.Sniffer-1.2.12-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **Consolidated 8-Domain Sidebar:** Reduced the sidebar from 11 fragmented items to 8 core investigation domains: Overview, Issues, Diagnostics, Nodes, Storage, Queries, Logs, and Config.
- **Unified Tracelog Exploration:** Merged `Logs` and `Log Search` into a single, cohesive **Logs** view with sub-navigation between *Log Search & Context* (raw grep with context lines and regex) and *Log Stream* (sequential pagination).
- **Integrated Storage & Disk Intelligence:** Integrated Disk Intelligence directly into the **Storage** tab as a native sub-view alongside Databases, Disk Usage, Partitions, and Tables.
- **Decluttered Landing Page:** Removed non-essential 30-day upload sparklines and vanity trend deltas from the home screen, allowing support engineers to see their report table immediately without vertical scrolling. Gated the snapshot comparison bar to appear only when reports are selected.
- **Dead Code Pruning & Air-Gap Hardening:** Removed disconnected Hostinger cloud extension routes, orphaned `TopologyMap.jsx`, and internal migration parity tables. Strict local CSP (`connect-src 'self'`) is now enforced across the app.
