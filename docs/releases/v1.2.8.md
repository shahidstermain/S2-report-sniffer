# S2 Report Sniffer v1.2.8

## Complete checker grounding, SuperChecker analysis hardening, truthful evidence coverage, and expandable storage overhead details

Version 1.2.8 ensures 100% SuperChecker ID grounding in `backend/grounding.py`, hardens report analysis against null and malformed node metrics across 29 crash paths, corrects the Evidence Coverage calculation in report overview, and adds interactive click-to-expand details for Cluster Overhead in disk storage diagnostics.

## Highlights

- **100% SuperChecker grounding:** Added official documentation groundings for `cpuGovernor` and `cpuIowait` in `backend/grounding.py` alongside an automated regression test verifying every registered checker ID has a verified or heuristic basis.
- **SuperChecker analysis resilience:** Hardened `_CheckerState`, `_check_used_cluster_capacity`, and incident cluster grouping against `None` values, corrupted dictionaries, and non-numeric fields across 29 analysis paths, preventing unhandled exceptions when processing partial or corrupted cluster bundles.
- **Truthful evidence coverage calculation:** Updated `_health_coverage(payload)` in `backend/server.py` to evaluate actual payload sections (`mv_nodes`, `cluster_status`, `show_variables`, `processlist`, and `tracelogs`) rather than solely relying on `dmesg`.
- **Interactive Cluster Overhead breakdown:** Added click-to-expand explanation panels for `CLUSTER OVERHEAD` and its child breakdown categories (`other_overhead`, etc.) in `StorageDistribution` and `DiskIntelligence`, providing immediate clarity on mount filesystem metadata, OS temp files, and engine binaries.
