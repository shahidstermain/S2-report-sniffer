# S2 Report Sniffer v1.2.9

## Query Tracer and drawer window-anchoring fix

Version 1.2.9 fixes the Query Tracer opening off-centre and clipped at the right edge of the window, with the sidebar left undimmed.

## Download

Expand **Assets** on the [v1.2.9 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.9):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2.Report.Sniffer-1.2.9-arm64.dmg` |

Verify the package against `SHA256SUMS-macos` or `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2.Report.Sniffer-1.2.9-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **Query Tracer anchored to the window:** The page fade-in animation (`.animate-fade-in`) used `animation-fill-mode: forwards`, which left a CSS `transform` on the Overview, Queries, and Issues page wrappers. A transformed ancestor becomes the containing block for `position: fixed` descendants, so the Query Tracer overlay was sized to the scrolling content pane. The animation now uses `backwards` and looks the same, and the Issues finding drawer is fixed by the same change.
- **Query Tracer rendered at the document root:** The tracer is portaled to `<body>` so future ancestor styling cannot misplace it, and it exposes `role="dialog"` / `aria-modal` to assistive technology.
- **Regression coverage:** Tests assert portal placement under a transformed ancestor and guard the fade-in fill mode in both stylesheets.
