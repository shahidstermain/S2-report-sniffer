# S2 Report Sniffer v1.2.5

## Evidence-first SingleStore diagnostics for macOS, Windows, and Linux

Version 1.2.5 completes the grounded-analysis release with native desktop packages and deterministic SHA-256 manifests for every supported platform.

## Download

Expand **Assets** below:

| Your computer | Package |
|---|---|
| macOS — Apple Silicon (M1/M2/M3/M4) | `*-arm64.dmg` |
| macOS — Intel | the other `.dmg` |
| Windows 10/11 x64 | `.exe` |
| Linux x64 | `.AppImage` or `.deb` |

Verify the package against the matching `SHA256SUMS-*` manifest:

```bash
shasum -a 256 "/path/to/downloaded/package"
```

> **Unsigned community build:** macOS and Windows may show an unidentified-developer warning. Download only from this official repository and verify the checksum. On macOS, Control-click the app and choose **Open**. On Windows, choose **More info → Run anyway**.

## Highlights

### Query analysis that respects source semantics
- Processlist time is current-state age, not assumed end-to-end runtime.
- Sleeping/system sessions are excluded from active-query findings.
- Blocker identities and `REASON_FOR_QUEUEING` use documented fields.
- Query-scoped evidence is separate from node-level log-window correlation.
- Unverified partition routing is labeled unknown.

### Replication analysis without invented lag
- Measured elapsed lag is separated from LSN/volume backlog and catch-up estimates.
- Connectivity, paused links, throttling, async transitions, backlog, and unknown lag are independent signals.
- Historical transitions alone do not claim a current critical failure.

### Explainability and transparency
- New KPI/checker explainer catalog and `/api/explainers` endpoints.
- Documented behavior, Toolbox defaults, observations, and Sniffer heuristics are distinguished.
- The score is documented as a **Finding Severity Index**, not official cluster health.

### Accuracy, security, and packaging
- CPU/network counters are labeled cumulative since boot; loopback traffic is excluded.
- Replica roles and incomplete topology inputs are handled honestly.
- Table-skew analysis uses exact population CV, correct MiB units, and guarded idle-leaf detection.
- Backend, frontend, Electron, and packaging dependencies are updated past known production advisories.
- Multi-resolution Windows icon, native Windows/Linux backend paths, and cross-platform checksum generation are covered by regression tests.
