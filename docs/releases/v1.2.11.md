# S2 Report Sniffer v1.2.11

## AI Root-Cause Analysis & Incident Export Enhancements

Version 1.2.11 elevates AI-driven root-cause analysis (RCA) across both **Analyse in Glean** and **Export JSON**, injecting deep cluster topology, active workload snapshots, lock wait chains, and structured investigation guidance.

## Download

Expand **Assets** on the [v1.2.11 release](https://github.com/shahidstermain/S2-report-sniffer/releases/tag/v1.2.11):

| Mac | Package |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `S2.Report.Sniffer-1.2.11-arm64.dmg` |

Verify the package against `SHA256SUMS-macos` or `SHA256SUMS-mac-arm64`:

```bash
shasum -a 256 "/path/to/S2.Report.Sniffer-1.2.11-arm64.dmg"
```

> **Unsigned community build:** Control-click the app and choose **Open** on first launch. Download only from this official repository and verify the checksum.

## Highlights

- **Cluster Topology & Node Health:** Incident packets now feature complete cluster topology detailing Master Aggregators, Child Aggregators, Leaves, Availability Groups, and explicit offline or degraded node flags.
- **Active Workload & Contention Snapshot:** Captures executing connections with elapsed seconds and query text, lock contention chains from `MV_BLOCKED_QUERIES`, workload management queues, and queries running longer than 30s.
- **Structured AI RCA Prompt:** Upgrades the suggested Glean Chat prompt to demand structured blast radius analysis, primary trigger vs secondary cascading symptom separation, disproven hypotheses, and exact SingleStore SQL remediation steps.
- **Dedicated AI JSON Export:** Implements `GET /api/reports/{id}/export/json` and enhances the Recommendations **Export JSON** action to download a comprehensive, AI-ready JSON incident packet with offline fallback.
