# Guided demo mode

Guided demo mode lets a first-time user explore S2 Report Sniffer without a real SingleStore Cluster Report.

## Enable / launch

1. Start the app normally.
2. Open the report list.
3. Select **Launch Demo Workspace** or open **Guided help → Launch Demo Workspace**.

The backend creates two synthetic reports:

- **Demo: Active Incident** — intentionally degraded signals across topology, memory, disk, backups, long-running queries, config, and tracelogs.
- **Demo: After Remediation** — improved follow-up snapshot for comparison.

Demo reports are marked with a **Synthetic demo data** badge and is_demo=true. They contain no customer data and are excluded from normal report-list KPI totals.
Their Finding Severity Index uses the same critical/warning weighting as imported reports; demo values are not independently hardcoded.

## Guided features

- **Quick tour** walks through the report list and dashboard.
- **Explain this page** adds contextual page guidance and top glossary entries.
- **Metric glossary** explains meaning, source, calculation basis, interpretation, next investigation step, and limitations.
- Dashboard tour steps navigate only across tabs available for the current report.
- The tour behaves as a keyboard-modal dialog and can be closed with **Escape**.
- Guided help opens in a viewport-bounded modal, so its controls and glossary remain visible in compact desktop windows.

## Disk presentation scenario

The synthetic incident includes presentation-ready disk evidence:

- per-leaf filesystem usage, including leaves at 88% and 92%;
- database-attributed bytes versus transaction logs, snapshots, tracelogs, spill, and unattributed overhead;
- per-node on-disk versus HA-adjusted referenced blob estimates;
- columnstore and rowstore table inventory plus partition distribution;
- disk-pressure and fsync log evidence; and
- a post-remediation snapshot with lower mount usage, spill, and estimated blob delta.

All values are explicitly synthetic. Reclaimable bytes and HA-adjusted blob deltas are labeled as Sniffer estimates and are not delete instructions.

## Data boundaries

Demo mode is local-first and offline. The synthetic data is generated by the backend and persisted through the same local storage path as normal reports. No telemetry or customer diagnostics are sent anywhere by launching demo mode.
